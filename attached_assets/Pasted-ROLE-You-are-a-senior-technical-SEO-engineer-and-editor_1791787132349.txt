4. /robots.txt: allow all crawlers, reference only the canonical sitemap, block /api and any admin routes.
5. /sitemap.xml: include ONLY indexable canonical 200 URLs, with accurate lastmod (from real update dates). Add a news sitemap only for articles under 2 days old. Exclude anything noindexed, redirected, or retired. Split into sitemap index files if needed.
