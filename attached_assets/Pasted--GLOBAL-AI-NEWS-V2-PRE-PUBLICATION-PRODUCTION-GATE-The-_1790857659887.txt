# 8. AUTHOR ATTRIBUTION

The explicit-author requirement is correct.

Maintain this rule:

> Never invent an author.

If an article has no valid author:

```text
Byline unavailable
```

is preferable to fake attribution.

Verify production article pages show:

```text
Author name
Author profile link
Publication date
Modified date where applicable
```

Never expose:

```text
ananya-rao
lena-hoff
```

as the primary human-facing author label.

Use:

```text
Ananya Rao
Lena Hoff
```

Human-readable date:

```text
September 23, 2026
```

not:

```text
2026-09-23
```
