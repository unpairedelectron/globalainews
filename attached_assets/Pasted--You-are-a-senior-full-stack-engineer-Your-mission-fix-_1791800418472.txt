## Root causes to look for (likely)
- Templates rendering a single object instead of iterating an array.
- Backend queries using `LIMIT 1` or returning a single record for each section.
- Image URLs stored as relative or missing protocol (e.g., `//` or `http` causing mixed content).
- CDN or S3 bucket permissions or missing CORS headers.
- Static files not served from root (ads.txt placed in wrong folder).
- CSS/JS causing layout collapse or defaulting to a dark/unstyled theme (missing CSS or fonts).

### A. Make sections show multiple items (backend + template)
**Action checklist**
1. Search codebase for section queries and templates:
   - Keywords: `getLatestBySection`, `limit: 1`, `per_page`, `section.items`, `featuredArticle`, `leadArticle`.
2. Update backend query defaults to `per_page = 8` (or 4 minimum) and support `?page=` and `?per_page=`.
3. Update templates to iterate arrays and render grid cards.

**Node/Express + Postgres example**
```js
// routes/sections.js
router.get('/api/section/:slug', async (req, res) => {
  const perPage = Math.min(parseInt(req.query.per_page) || 8, 50);
  const page = Math.max(parseInt(req.query.page) || 1, 1);
  const offset = (page - 1) * perPage;
  const items = await db.query(
    `SELECT id, title, slug, image_url, excerpt, published_at, author
     FROM articles
     WHERE section = $1 AND published = true
     ORDER BY published_at DESC
     LIMIT $2 OFFSET $3`, [req.params.slug, perPage, offset]
  );
  res.json({ items: items.rows, page, perPage });
});
```

**Template (Handlebars / Nunjucks / EJS)**
```html
<div class="section-grid">
  {{#each section.items}}
    <article class="card">
      <a href="/article/{{this.slug}}">
        <picture>
          <source srcset="{{this.image_url}}?w=800 800w, {{this.image_url}}?w=400 400w">
          <img src="{{this.image_url}}" alt="{{this.title}}" loading="lazy" onerror="this.src='/assets/fallback-{{section.slug}}.jpg'">
        </picture>
        <h3>{{this.title}}</h3>
        <p class="meta">{{this.author}} • {{formatDate this.published_at}}</p>
      </a>
    </article>
  {{/each}}
</div>
```

**If code uses a single `featured` object**:
- Keep `featured` for hero, but ensure `section.items` is an array for the grid. Do not reuse the same single object for both hero and grid.

**Tests**

### B. Fix missing article images
**Action checklist**
1. **Audit**: Run the discovery crawl above to list broken images and their HTTP status.
2. **Data fix**: For articles missing `image_url`, update DB to point to a fallback editorial image or a per‑section fallback.
   - SQL example:
     ```sql
     UPDATE articles
     SET image_url = '/assets/fallback-world.jpg'
     WHERE image_url IS NULL OR image_url = '';
     ```
3. **Ensure absolute HTTPS URLs**:
   - If stored as `//cdn.example.com/img.jpg` or `http://`, normalize to `https://cdn.example.com/img.jpg`.
4. **CORS**: If images are on S3 or external CDN, ensure `Access-Control-Allow-Origin: *` or your domain.
5. **Template**: Use `srcset`, `sizes`, `loading="lazy"`, and `onerror` fallback.
6. **CDN**: If using CloudFront or similar, invalidate cache after fixes.

**Responsive image example**
```html
<picture>
  <source media="(min-width:900px)" srcset="{{image_url}}?w=1200">
  <source media="(min-width:600px)" srcset="{{image_url}}?w=800">
  <img src="{{image_url}}?w=400" alt="{{title}}" loading="lazy" onerror="this.src='/assets/fallback-article.jpg'">
</picture>
```

**S3 CORS example (bucket CORS config)**
```xml
<CORSConfiguration>
  <CORSRule>
    <AllowedOrigin>*</AllowedOrigin>
    <AllowedMethod>GET</AllowedMethod>
    <MaxAgeSeconds>3000</MaxAgeSeconds>
    <AllowedHeader>*</AllowedHeader>
  </CORSRule>
</CORSConfiguration>
```

### E. SEO, Open Graph, JSON‑LD, sitemap, robots
**Add to article templates**
- `<title>`, `<meta name="description">`, canonical link.
- Open Graph:
```html
<meta property="og:title" content="{{title}}">
<meta property="og:description" content="{{excerpt}}">
<meta property="og:image" content="{{image_url}}">
<meta property="og:type" content="article">
<meta property="og:url" content="https://globalainews.in/article/{{slug}}">
<meta name="twitter:card" content="summary_large_image">
```
- JSON‑LD (NewsArticle):
```html
<script type="application/ld+json">
{
  "@context":"https://schema.org",
  "@type":"NewsArticle",
  "headline":"{{title}}",
  "image":["{{image_url}}"],
  "datePublished":"{{published_at}}",
  "author": {"@type":"Person","name":"{{author_name}}"},
  "publisher":{"@type":"Organization","name":"Global AI News","logo":{"@type":"ImageObject","url":"https://globalainews.in/logo.png"}}
}
</script>
```
- Generate `sitemap.xml` and submit to Google Search Console.
- Ensure `robots.txt` allows crawling:
```
User-agent: *
Allow: /
Sitemap: https://globalainews.in/sitemap.xml
```
