================================================

1. CURRENT WORKSPACE IS SOURCE OF TRUTH
---------------------------------------
Use the current workspace revision as the intended production source.

Never assume that a successful deployment means the correct revision
is serving production.

2. FIX ROOT CAUSES
------------------
Do not repeatedly patch symptoms.

When production behavior disagrees with workspace behavior:

- inspect deployment topology
- inspect build source
- inspect artifact provenance
- inspect routing ownership
- inspect environment configuration
- inspect caches/static artifacts
- identify the actual serving process
- identify the exact stale layer

-------------------------------

records in production.

- staging database

wherever possible.

-----------------

- sources
- citations
- URLs
- data
- research findings
- legal text
- editorial claims
- publication dates
- author information
- methodology
- statistics

5. PRESERVE EXISTING GOOD BEHAVIOR
----------------------------------

verification.

-----------------
Do not create:

- mass-generated thin pages
- empty entity pages

- keyword-doorway pages

Build a real publication, not a page-count machine.
