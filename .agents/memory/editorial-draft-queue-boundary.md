---
name: Editorial draft queue boundary
description: The newsroom release queue schedules public publication rather than storing private drafts.
---

Do not use the newsroom release queue to store unpublished editorial drafts. Creating a queue record gives it a publication time and can make it public automatically; until the product has a true private-draft status, keep research drafts outside the public snapshot and release queue.

**Why:** Draft-only work must not publish itself merely because a future date arrives.

**How to apply:** Before saving editorial copy through the release API or UI, confirm whether the record is private or scheduled for public release. For private review material, use a non-public repository document or implement a distinct draft state with publication safeguards.
