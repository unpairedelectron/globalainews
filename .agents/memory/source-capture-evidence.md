---
name: Source capture evidence
description: Validate captured source content before citing it in research and editorial drafts.
---

A source is usable only when the captured body contains evidence for the claim being cited. A successful fetch, page title, search snippet, or navigation shell is not enough to support a study’s methods, findings, or limitations.

If a primary page is inaccessible or only exposes metadata, find an accessible official overview or a credible independent source and narrow the claim to what that source actually supports. If no suitable evidence is available, exclude the empirical claim rather than inferring it from the source title.

A trailing anti-bot challenge does not invalidate relevant article text already captured above it. Verify the exact claim-bearing passage and distinguish that case from a page where the challenge replaces the article body.

For inventory PDFs, distinguish file metadata dates from source-printed publication or as-of dates. A creation timestamp does not identify when the inventory was measured, what its counts represent, or how they relate to operational stages.

**Why:** Page retrieval can succeed without exposing the article or report body; a trailing challenge can also create a false positive when only page endings are scanned. File properties can provide a date without establishing the underlying snapshot date or denominator.

**How to apply:** Before adding a citation, inspect the saved text and verify the exact attribution, source-printed date, count unit/denominator, operational stage, and limitation relevant to the sentence. If a challenge appears, check whether the cited passage precedes it. Label metadata dates only as file metadata; do not infer a crosswalk when the source leaves these fields undefined.
