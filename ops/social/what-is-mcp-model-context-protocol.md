## LinkedIn
The MCP specification says a human should always be able to deny an AI's tool calls, and that tool descriptions should be treated as untrusted.

The Model Context Protocol, open-sourced by Anthropic in November 2024, is now supported by Claude, ChatGPT, VS Code and Cursor. Its 2026-07-28 version dropped the opening handshake and sessions entirely.
