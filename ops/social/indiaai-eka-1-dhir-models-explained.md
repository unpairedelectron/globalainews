A 1.21 GB file can now run an Indian-built language model offline on an ordinary laptop.

On 3 November the IndiaAI Mission released three foundation models: Soket's EKA-1 (26.3 billion parameters, trained on about 7.5 trillion tokens, all 22 scheduled Indian languages) and ZenteiQ's Dhīr 2B and Dhīr 5B, compact Apache 2.0 models for English and ten Indian languages.

We explain what each model is built for, the developers' own benchmarks and limits, and why only Dhīr has a public download so far.
