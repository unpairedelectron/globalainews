## Evidence relevant to this explainer

The NIST glossary cites NIST AI 100-2e2025. It defines RAG as a generative-AI system paired with a separate information-retrieval system or knowledge base. The retrieval system identifies material relevant to a query and supplies it in the model's context; this can modify the information used by the system without retraining the model.
