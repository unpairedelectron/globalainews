## Evidence relevant to this explainer

For its study, Anthropic operationalizes an agent as an AI system equipped with tools that let it take actions, such as running code, calling external APIs or messaging other agents.

## Limits

This is a study-specific operational definition from one model provider and one provider's usage data. It is not a universal definition or a neutral census of all agents.
