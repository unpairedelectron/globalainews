## Evidence relevant to this explainer

Anthropic distinguishes workflows, where language models and tools are orchestrated through predefined code paths, from agents, where the model dynamically directs its process and tool use. The article describes retrieval, tools and memory as possible augmentations to an LLM.

## Limits

This is a provider's engineering framing, not an industry-wide formal definition. Anthropic's page notes that parts of its tooling landscape have changed since publication. Use it to explain one useful architectural distinction, not to define every product marketed as an agent.
