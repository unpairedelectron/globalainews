Title: The Open Source AI Definition — 1.0
Fetched: 2026-10-04

## Evidence relevant to this explainer

The Open Source Initiative's version 1.0 definition grants four freedoms: use, study, modify and share. It says users need access to the preferred form for making modifications. For machine-learning systems, the definition identifies data information, code and parameters as required components of that preferred form; parameters include weights and other configuration settings.

## Limits

This is OSI's definition, not a universal legal definition adopted by every jurisdiction or model provider. The page alone does not determine whether a specific model package meets the definition; that requires reviewing the actual terms and available data information, code and parameters.
