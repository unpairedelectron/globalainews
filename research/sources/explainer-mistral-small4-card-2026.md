## Evidence relevant to this explainer

The official model page labels Mistral Small 4 as Apache 2.0 and an open-weights model. It lists 119 billion total parameters, 6.5 billion active parameters and a 256K context window.

## Limits

These are provider-published specifications, not independent measurements of quality, latency, memory use or local hardware fit. The “active parameter” count is not the model's total stored weight size and should not be used alone to estimate deployment memory.
