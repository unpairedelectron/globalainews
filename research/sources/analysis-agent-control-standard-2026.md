## Relevant evidence

OWASP’s GenAI Security Project describes the Agent Control Standard as an open foundation for making agents inspectable, traceable and instrumentable. The project says the standard defines how agent platforms expose middleware hooks and how safety policies can be enforced through those hooks, with declarative controls intended to work across agent frameworks and be enforced at runtime.

Use this page to describe OWASP’s stated goals and scope for ACS. It is a project standard, not a regulation or evidence that all agent platforms implement these controls.
