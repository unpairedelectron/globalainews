# IndiaAI Compute Capacity: GPU Compute Allocation

Source: https://indiaai.gov.in/hub/indiaai-compute-capacity  
Publisher: IndiaAI Portal  
Fetched: 2026-10-04  
Page publication/as-of date: not stated

## Relevant primary evidence

The IndiaAI hub page has a “GPU Compute Allocation” section and describes compute being offered to registered and approved users. Its visible allocation rows carry individual allocation timestamps; the captured rows are dated from 23 April through 30 May 2025. The table headings include GPU count and type, service provider, user category, project duration, and the date by which the applicant must start using the allocation.

The row-level table is evidence that project allocations were recorded with a device count, accelerator type, provider, and project dates. It is not a provider hardware census. The page does not establish that an allocation was delivered, installed, commissioned, started, still active, or available to another user. It provides no dated aggregate of currently schedulable GPUs, active reserved GPUs, or metered GPU-hours. Applicant names are intentionally not reproduced in this research note.

## Scope and citation use

Use this source to describe the existence and fields of dated project-level allocation records only. Do not sum the visible rows into programme-wide supply or interpret a “date by which applicant must start using” as proof that use began.
